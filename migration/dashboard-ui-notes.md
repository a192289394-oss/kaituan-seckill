# dashboard.keyframe-gz.com UI 设计要点（迁入开团/秒杀用）

来源：2026-10-16 只读观察，已登录经营总览。

## 滚动（迁入最要紧）

- 宽屏（≥961px）：左侧栏 `position: fixed`（宽约 208px，圆角 26px），主区 `margin-left: 244px`。滚的是整页；侧栏不会因主列表下滚而空掉。
- 现网 kaituan 问题：右侧任务列表下滚后左边提交区空一大截——迁入时不要再做「会跟着列表滚走的左栏」；提交区放主列，或沿用 dashboard 固定侧栏只放菜单。
- 窄屏 ≤600px：侧栏回文档流，长列表时导航离开视口（可接受用下拉）。

## 骨架

- 单页 hash：紫渐变固定侧栏 + 浅紫灰主区。
- 菜单示例：经营总览、跟进人业绩、直播排班、直播与短视频、商家业绩、房态巡查、预售券预约离店、客户工作台等。
- 内页两种：壳内直绘；或 iframe（注意双顶栏，优先 `embedded=1` 无壳）。

## 视觉 token（对齐用）

- 字：Avenir Next / PingFang SC；正文 14px/1.6
- 主色紫 `--pine #6651a7` / `--pay #6b53ae`；强调粉 `--confirm #d14f87`
- 底 `#f6f5fa`；边 `#e9e5f1`；字 `#39334e` / muted `#777187`
- 涨绿 `#338170`、跌玫瑰 `#bf5268`；勿换成通用后台大红大绿
- 主按钮实心紫胶囊；次按钮白底浅紫描边；卡片圆角 14–20

## 开团/秒杀建议

1. 新菜单项进 `#primary-nav`（20px 图标 + 文案）
2. 内容在主区；筛选/提交/任务进展都在主列，避免左右分栏滚动脱节
3. 若 iframe 嵌入，默认用无壳嵌入，避免双顶栏
4. 状态色跟 dashboard 绿/玫瑰
