## 1. 目标形态（建议）

| 块 | 迁后建议 |
|---|---|
| 操作员 UI | 并入 dashboard 同一套导航/壳；路由例如 `/kaituan` 或 dashboard 子菜单「开团与秒杀」 |

## 2. 域名与入口切换（要拍板）

待产品/姐姐确认一项：

**A. 同域反代（推荐）**  
`dashboard.keyframe-gz.com/kaituan/`（或 `/api/kaituan/`）→ 现网关进程。  
- Cookie `Path` 要对齐新路径（现网关已支持 `cookie_path`）。  
- CORS / `allowed_hosts` / `public_origin` 改成 dashboard 域名。  
- 旧 `1.12.208.101/kaituan/` 可短暂双活或 302。

**B. 独立子域**  
如 `kaituan.dashboard…` —— 鉴权要和 dashboard SSO 打通，工作量更大。

**C. 彻底并入 dashboard 后端**  
把队列写进 dashboard 服务 —— **本期不做**（风险大、易丢只提交一次语义）。

架构默认按 **A** 准备。

## 6. 硬规则（迁时零丢失 · 与风控对齐）

迁入验收必须覆盖：

1. 每单只提交一次 + 提交后回读  
2. 开团免确认；秒杀唯一直加 / 多选；无生效活动拒建、零新建  
3. `write_ready` / 人话顶栏；掉登停写；自愈不重提业务  
4. 连败 / 限流 / 自愈上限停写数字不变  
5. 秒杀人工确认路径（多活动选择）仍在  

架构侧保证：**gate/commit 双调与 journal 不被「合成进 dashboard」时拆坏**。

## 11. 与 dashboard UI 纪要对齐（2026-10-16 补充）

来源：`dashboard-ui-notes.md`。

- **UI**：开团进 dashboard 固定侧栏菜单；提交 / 任务进展都在**主区**，不再做会跟着列表滚走的左栏（从根上消掉空档）。优先无壳嵌入，避免 iframe 双顶栏。
- **API（架构）**：仍建议同域反代挂载现网关，例如：
  - 页面：`https://dashboard.keyframe-gz.com/#…`（壳内路由，前端定）
  - Worker / API 基址：`https://dashboard.keyframe-gz.com/kaituan/`（或 `/api/kaituan/`）→ 现网关
- Mac `--server` 只填 **API 基址**，不要填成带 hash 的前端路由。
- 切流仍按上文顺序；材料已齐，等产品钉登录方式 + 最终路径字符串后可出「改哪几行」补丁清单（仍不真迁）。

- **操作员**：与经营台同一套登录；进「开团与秒杀」零二次登录。旧 kaituan 独立登录页不再当主入口。

## 14. 现网鉴权事故备忘

### 主站会话参数（姐姐 2026-10-16）

- Cookie：`__Host-site_session`，Path=/，Max-Age=**30 天**，Secure; HttpOnly; SameSite=Lax
- 挑战 cookie：`__Host-site_challenge`（10 分钟）
- 库：`/var/lib/site-entry/sessions.db`；改密码不清空已有 session
- 今日无批量踢登录证据；nginx reload ≠ 踢会话
（2026-10-16 · 姐姐核查）

- 操作员路径：全站 `site-entry`（`auth_request`）；仅 `/kaituan/api/worker/` 关闭主站鉴权。
- 今日 nginx 变更：新增 `/claude-chat/`，**未改**开团 snippet；与 sticky CSS 无关。
- **坑**：`GATEWAY_USER_TOKEN` 轮换后，`kaituan-auth-header.conf` 硬编码 Bearer 未同步 → 主站登录后仍可能 401。
- 修复优先：同步或取消 nginx Bearer 注入；勿为救急关掉整段 `/kaituan/` site-entry（与经营台同登录冲突）。
- 未授权不改生产；等暖暖转用户拍板。
