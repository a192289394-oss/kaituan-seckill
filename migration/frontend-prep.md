# 开团/秒杀 → dashboard 前端对齐方案（先准备、不真迁）

依据：姐姐 `/workspace/kaituan-project/migration/dashboard-ui-notes.md` + 现网空档截图 `kaituan-sidebar-gap.png`  
现网仍是 https://1.12.208.101/kaituan/

---

## 1. 对齐总原则

1. **嵌进经营台壳**：开团进 dashboard 左侧 `#primary-nav` 菜单；内容只画在主区。优先无壳嵌入，避免 iframe 双顶栏。
2. **视觉跟经营台**：浅紫灰底、紫主色、绿涨/玫瑰跌；不另立深蓝 Tabler / 深色独立站。
3. **滚动跟经营台**：宽屏侧栏 fixed 只放菜单；提交与「任务进展」都在主列，别再做「会跟着列表滚走的左栏」。
4. **能力不丢**：用法对齐已关单的那套（说明、秒杀添加、任务进展、无活动拒建无创建表单、掉登人话顶栏）。

---

## 2. 左侧空档：根因 + 迁入修法

**现象**：右侧任务列表下滚，左边「提交开团」下方空一大截（Jshs 吐槽点）。

**根因**：现网 `.layout` 两列 grid + `align-items: start`，左右同属文档流；右侧变长整页加高，左侧 composer 不钉住 → 下方露白。

**迁入推荐（跟 dashboard 一致，优先于旧 sticky 两列）**

| 优先级 | 方案 | 做法 |
|---|---|---|
| **P0 推荐** | **主列单栏** | dashboard 左菜单 fixed；开团页主区上：说明/模式/提交；下：「任务进展」列表。整页只滚主区，**取消左右分栏**，空档自然消失。 |
| P1 过渡 | 主区内上提交、下列表 | 若短期仍要并排：提交区放主列顶部通栏，列表在下，禁止左短右长并排。 |
| 仅现网补丁 | composer `position: sticky` | 未迁前可临时钉左栏；**迁入后不要再依赖「左提交右列表」**。 |

验收：任务 ≥10 条滚到底，左侧不再空一大截；提交区始终在主列可达位置。

## 3. 视觉 token 映射（现 kaituan → dashboard）

| 用途 | 现 kaituan（Tabler 蓝） | 对齐 dashboard |
|---|---|---|
| 主色/主按钮 | `#206bc4` | `#6651a7` / `#6b53ae`（紫胶囊） |
| 背景 | `#f4f6f8` | `#f6f5fa` |
| 边框 | `#e6e8eb` | `#e9e5f1` |
| 正文 | `#1e293b` | `#39334e` |
| muted | `#64748b` | `#777187` |
| 成功 | `#2fb344` | `#338170`（涨绿） |
| 失败/危险 | `#d63939` | `#bf5268`（玫瑰）/ 强调粉 `#d14f87` |
| 卡片圆角 | 6–8px | 14–20px |
| 字 | 系统黑 + PingFang | Avenir Next / PingFang SC，14px/1.6 |

动作：改 `style.css` 的 `:root` 变量；主按钮改实心紫胶囊、次按钮白底浅紫描边；徽章 ok/bad 换绿/玫瑰。去掉独立站大顶栏品牌，闸/掉登改页内 banner（跟壳通知条气质一致）。

## 4. 信息架构（主区）

```
[dashboard 左菜单 · 开团与秒杀]     ← 固定，产品定名
主区：
  ① 人话说明（开团三步 / 秒杀添加规则）
  ② 闸状态 / 掉登红字（页顶 banner）
  ③ 提交区（模式切换 + 表单 + 提交按钮）
  ④ 「任务进展」（标题加大，列表可长滚）
```

不推荐：主区内再左右分栏滚动。
