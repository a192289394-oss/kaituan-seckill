# 开团/秒杀 → dashboard 迁后验收：风控硬规则清单

> 角色：风控测试官  
> 范围：迁入 https://dashboard.keyframe-gz.com/ 后必须仍成立；**先准备、不真迁**  
> 依据：现网用例 `/workspace/风控测试用例-开团秒杀.md`（§1.1 / §7 / 用法对齐关单口径）  
> 执行机：仍为 macOS（BlueStacks + 来客）

## A. 提交与回读（P0，丢了直接不过）

| # | 硬规则 | 迁后怎么验 | 过线标准 |
| --- | --- | --- | --- |
| A1 | 每单只提交一次 | 开团/秒杀各走一单正常提交 | 平台侧仅一次写操作；无二次 submit |
| A2 | 提交已发出（含超时/断连）只回读、不重发 | 提交后断网或无响应 | `waiting_review` + `committed=true`；文案「已提交、只回读、勿重发」；**无重发按钮** |
| A3 | 回读对不上不重发 | 人为制造回读字段不一致 | 转人工/`waiting_review`；不触发再提交 |
| A4 | 平台明确拒绝不重发 | 业务拒绝码 | `failed` + `platform_rejected`；任务结束 |
| A5 | 读失败只重试读 | AppReadUnavailable | worker 内最多再读 2 次（2s/5s）；上报 `waiting_device` + `read_failure_code`；**不**进 `needs_input`、不提交 |
| A6 | 两套计数不混 | 对照配置/日志 | 读短重试=2；已提交只读复核上限=24 |
| A7 | 未知不当 0 | 缺价/库存/人数字段 | 显示「未知」或标注未核实，禁止填 0 |

## B. 秒杀业务闸（P0，用法对齐已关单口径）

| # | 硬规则 | 迁后怎么验 | 过线标准 |
| --- | --- | --- | --- |
| B1 | 只往已有生效活动加号 | 唯一 / 多个 / 无活动各一单 | 唯一可加；多个须显式选择；**无活动拒绝** |
| B2 | 无生效活动零新建 | 无活动酒店「秒杀添加」 | 提示去来客自建；**无**填时间/参考失效活动创建表单；网关拒 `schedule` 类 resume |
| B3 | 开团免确认照旧 | 贴计划链接提交 | 仍自动排队执行（规则未改则保持） |

## C. 7×24 停写与自愈（P0）

| # | 硬规则 | 数字 | 过线标准 |
| --- | --- | --- | --- |
| C1 | 业务连续失败停写 | K=3 / 15min | `write_ready=false`；顶栏人话；新写入拒收 |
| C2 | 写入限流 | ≤6/账号·时；≤20/整机·时；间隔≥60s | 超限停写；不盲打 |
| C3 | 自愈上限 | 连败停手=2；≤3次/小时 | 触顶停写；**禁碰** gate/commit/自动登录 |
| C4 | 环境未就绪停写 | adb/root/来客/frida 等 | 顶栏中文；网页可核验不可写 |
| C5 | 掉登停写 | merchant_session 未确认 | 停写 + 顶栏红字；**不推送**（本轮口径）；不自动登录 |

## D. 迁入 dashboard 特有验收（P0）

| # | 项 | 过线标准 |
| --- | --- | --- |
| D1 | 鉴权/域名 | 同事登录 dashboard 后才能提开团/秒杀；Mac worker 只连新网关地址；旧 kaituan 地址切流方案有回滚 |
| D2 | 硬文案与状态 | 「任务进展」、已提交勿重发、拒建提示、停写人话在 dashboard 壳内仍可见、不丢义 |
| D3 | 无重发入口 | 新 UI 任何菜单/按钮不能绕过 committed 再提交 |
| D4 | 去重仍在 | `request_id` + business_key 双层去重迁后仍生效 |
| D5 | 布局不制造误操作 | 修左侧提交区滚动空档（sticky/整页统一滚）后：提交按钮与任务卡操作不因滚动错位误点；不出现「看不见进展却以为没提交」 |

## E. 明确「代码过、待抽检」（未知不当已验）

| 项 | 现状 | 迁后 |
| --- | --- | --- |
| 真没活动酒店实弹 | 逻辑已封，未打真单 | 迁后用一家真没活动店点一次「秒杀添加」 |

## F. 交付给姐姐汇总时的一句话

迁入 dashboard **不得削弱**现网风控：只提交一次、只回读不重发、无活动零新建、停写/限流/自愈、掉登停写、未知不当 0；UI 换皮与域名切换后按上表 P0 回归，未抽检项继续标待抽检。
