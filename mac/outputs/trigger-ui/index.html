怎么使用开团与秒杀

怎么开团

  1. 左侧选「直播开团」。
  2. 输入框粘贴来客计划链接。
  3. 点「提交开团」，自动排队。
  4. 到下方/旁边的「任务进展」看有没有完成，以及团长计划内的商品与佣金。

怎么加秒杀

由于秒杀价格直接对外，请自行设置好秒杀活动，这里只在原有活动中进行账号添加，避免出现价格误差。

  1. 左侧选「秒杀添加」。
  2. 搜索酒店；再填抖音号。
  3. 唯一活动：直接添加。
  4. 多个生效活动：请选择要加入的活动（旁边会显示秒杀已有人数，有数据才显示）。
  5. 没有生效活动：拒绝执行，请自行到抖音来客创建秒杀活动。

表单里若仍有「需要真正加号时再勾选」，只在确认要真正加号时勾上即可；引导主流程以「唯一则直接加」为准。

什么时候需要你点一下

需要你动手时，徽章会直接写清事项（例如「请选择本店秒杀活动」「本店没有生效中的秒杀，请先去抖音来客创建活动后再来加号」）。点「去处理」按提示操作。排队中、处理中请稍候，不用反复点。

完成后看什么

  • 状态「已完成」：开团看商品与佣金；秒杀看活动名、有效期与抖音号。
  • 状态「没做成」：看卡片上的人话原因，再决定是否重新提交。
  • 每张卡都有提交时间；完成的会显示完成时间，一眼能回答「做了没、什么时候完成」。
