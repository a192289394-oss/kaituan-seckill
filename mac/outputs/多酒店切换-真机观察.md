# 多酒店切换：真机观察

2026-09-18；仅文字读取与导航，未提交新计划，未截图。

## 入口与身份

手机本次实际操作的是抖音销帮（`com.bytedance.lifeservice.crm`）和抖音来客（`com.bytedance.ls.merchant`）。林客是服务商侧入口，本次没有将林客网页的 ID 或附身 URL 假设为手机切换参数。

来客可直接切换已绑定账号，销帮用于合作商家的检索与重新进入后台。二者不是同一张完整名单：本次来客列表读到 20 个账号，珠江宾馆与民族文化村则通过销帮进入。不能据此说只支持 20 家，也不能把每个公司账号算成一家门店。

## 来客直接切换

1. 我的 → 点击顶部昵称 → 个人中心。
2. 代运营上下文中第一行可能叫“公司”，点击后是“商户管理”；另一些上下文叫“切换公司”，可能进入带搜索框的“选择你的公司”。不能只固定一个按钮名称。
3. 商户管理区分“首页已展示”和“首页未展示”。未展示的账号名本身不能切换；先点击对应行“展示到首页”，再点击该账号卡片“切换商户”。首页展示上限为 20；程序不自动移除用户已有卡片腾位置。
4. 可能出现“切换后首页公司将替换 → 确认切换”，或“请选择你的身份 → 我是管理者”。
5. 等待经营首页加载，再到“我的 → 个人中心”读取原生“公司/切换公司”行核验实际账号，然后返回首页。经营功能先加载、账号卡片后加载；卡片还可能暂时缺少“当前”标记，所以程序不只依赖首页缓存。首轮曾出现网络接口异常，重新走完整切换后恢复，原因尚不能仅凭界面确定。

已手动验证：广州海俊酒店(广州北京路天字码头店)、怡禾酒店(广州塔客村店)，均进入正常经营首页。

本次为直切验证将海俊、怡禾加入了首页展示列表，未删除其他商户；可在商户管理中“取消展示”恢复。展示操作不等于新增商户授权。

首页会保留其他已展示酒店的名称。不能拿未标记的卡片当成当前身份；“页面有目标酒店名”不是切换成功的证据。程序最终使用个人中心的公司行核验。

## 销帮备用入口

合作 → 搜商家名/门店名/品牌名搜索 → 输入全名 → 键盘搜索 → “合作中”过滤 → 唯一同名“签约商家” → 商家详情 → 商家后台 → 来客。

已手动验证珠江宾馆。未过滤时，同名结果混有广州、洛阳等城市的线索；不能点击第一个同名条目。不同合作类型也可能出现同名合同，不能随意挑一个。

## 公司和门店不能混用

民族文化村酒店的来客当前账号名为“广州绿美乡居公寓有限公司”，酒店全名为“广州天河民族文化村生态度假酒店”。这是已真机核对的特定映射，不代表其他公司名可以按相似度推断门店。

多门店集团、区域账号还需要进一步定位具体门店。当前自动化对于新出现的公司名与目标酒店名不一致情形会停止并报原因，不把总部默认成某家门店。

## 执行规则

- 接受自然表达中的酒店名称，不再要求固定“开团”口令或括号格式；支持“重开”“帮忙开一下”、额外 @ 称呼、礼貌用语和全半角标点。酒店名称对照真实候选匹配，唯一简称可自动补全；明确的分店不同不作相似匹配。
- 优先在来客商户管理核验并切换；找不到或切换异常时尝试销帮合作搜索。
- 找不到唯一账号、公司门店映射不明确、权限不足或页面异常时，不提交。
- 计划页另行核验完整酒店名、计划编号、直播类型与待确认状态。
- 已有任务的酒店不能通过重复发送另一家酒店名来替换。
- 所有回执仅文字；不增加截图、图片上传或新业务提交。

- 怡禾酒店：来客商户管理直切，个人中心公司精确核验通过，约 35 秒。
- 民族文化村：销帮合作搜索，来客个人中心公司映射核验通过，约 39 秒。
- 珠江宾馆：本轮手动逐步操作验证销帮搜索与后台跳转；未将手动结果冒充整段程序验收。
- 本地 19 项测试通过，覆盖账号卡片与实际公司识别、行内按钮归属、不同酒店名称、计划串店拦截、队列去重及提交前后恢复。
- 实测中出现过页面加载超时，程序按失败停止；未宣称所有网络状态均能自动恢复。

## 自然消息与湖滨店专项修复

用户原文含“@蓝莓 肇庆白天鹅迎宾馆（肇庆湖滨店），重开”和链接。原程序只接受“开团”关键字，返回帮助而未入队；本次已修复，不再让用户改写为固定模板。

- 真实销帮候选为“白天鹅迎宾馆(肇庆湖滨店)”。城市放在品牌前面与分店括号内的重复情况可自动对应，不能仅凭品牌给另一城市/分店开团。
- 该店的公司账号为“广州白天鹅酒店管理有限公司”；本次从唯一合作中签约条目、重复显示酒店全名的详情页进入来客，再从个人中心核验公司。
- 这家使用“行业通用版”，首次可能出现版本选择。新版无底部“我的”，需要点首页左上头像打开个人侧栏，进入个人中心；返回时使用侧栏原生返回按钮，不能套用酒店旧版底部导航。
- 同一公司包含多个酒店时，已知公司与酒店不同的任务优先通过销帮精确门店进入，不直接切到公司就默认是目标子店。
- 计划标题“肇庆白天鹅迎宾馆（肇庆湖滨店）-长和同尘”和销帮正式店名差一个重复城市前缀；计划校验允许这个差异，但品牌全名、分店与计划 ID 均须吻合。
- “重开”不会绕过已有计划防重；“不要开”“先看看”“等我确认”等不会创建即时执行任务。
